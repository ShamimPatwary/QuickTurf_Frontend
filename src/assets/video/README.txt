Specs that work well for a full-bleed hero background:
- Format: .mp4 (H.264)
- Orientation: landscape, ideally 1920x1080 or larger
- Length: 10-30 seconds, loopable (the component sets loop + muted + autoPlay)
- Keep file size reasonable for web (a few MB) — trim/compress if the source is very large

If this file is missing, HeroSection in src/pages/public/HomePageV2.jsx automatically
falls back to the static SVG illustration (hero-night-pitch.svg) — the page will never
break, it just won't have a video background until you add this file.
